# job

Everything about one job: plans, permits and their hours, upcoming shifts with problems, and incidents.

Run `node scripts/traffic.mjs job <job>`. Add `--json` when you need every field. Resolve the job, shift, worker, vehicle or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Lead with whether the next shift can start.
