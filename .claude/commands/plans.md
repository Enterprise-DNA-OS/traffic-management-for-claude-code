# plans

Every traffic management plan and guidance scheme not yet obsolete, unapproved first, with the dates it covers and the crew it calls for.

Run `node scripts/traffic.mjs plans`. Add `--json` when you need every field. Resolve the job, shift, worker, vehicle or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Flag plans not approved with shifts ahead.
