# incidents

Every incident, newest first, with whether the client and regulator have been told. --open hides closed ones.

Run `node scripts/traffic.mjs incidents [--open]`. Add `--json` when you need every field. Resolve the job, shift, worker, vehicle or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Lead with any notifiable event the regulator has not heard about.
